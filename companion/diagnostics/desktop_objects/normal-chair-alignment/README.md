# Normal chair contact check

This is a Linux native reconstruction using the installed Cheval source entry/idle and production skinned pelvis/thigh calibration, with avatar scale 0.6 and source-derived chair scale 0.543706. It is not a replay of the original Windows skeleton snapshot. `probe_normal_chair_alignment.gd` creates only an owned local viewport and saves side/oblique views.

The real imported chair's lowest vertex is at world Y -8.1e-9 m; the selected skinned foot geometry minimum is -22.9 micrometres. Both chair and character face +Z. The measured underside seat anchor equals the actual seat socket exactly. Downward rays on the actual imported upholstery at the center and bilateral x ±0.06 asset metres put the cushion surface 4.85–4.96 mm above that anchor: small overlap rather than an air gap. The hip bone sits about 60 mm above the cushion anchor, consistent with bone-to-skin offset; placing that bone directly on the cushion would be incorrect.

Visual inspection of `side.png` and `oblique.png` shows the butt/thigh resting on the cushion and boots/casters at the same physical floor. Thus this reconstruction does not support a reversed-chair or hovering-body diagnosis from the previous front still. It does show cape/tail contact limitations; no full clothing or hair collision is established. Windows root telemetry independently reported matching facing, 0.000122-pixel anchor residual and a 0.322-mm live-foot residual in its recorded seated frame. That telemetry is a separate observation, not evidence that these reconstructed vertices are the identical Windows pose.
