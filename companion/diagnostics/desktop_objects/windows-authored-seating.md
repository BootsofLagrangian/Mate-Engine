# Authored seating temporal Windows probe

`native/tools/probe_windows_authored_seating.gd` is an opt-in production-scene probe. Root exclusively launches Windows. No Windows run or natural choreography approval is claimed by this document.

Arguments: `--output ABS_DIR [--character cheval-grand|rice-shower|eishin-flash] [--abort-case none|cancel|support_loss]`. Run each rig separately. The normal path uses validated direct furniture skills for chair sit→normal stand and computer use→10-second work→normal stand. It does not inject or register authored clips: production backend/manifest readiness must provide both transition registrations. A 180-second watchdog bounds the run. Original settings are restored and only owned viewports are captured.

Each rendered frame retains an owned PNG, CSV and detailed JSON sample: phase, OS origin, actual source time/progress/root curve, source rotations, world hips/knees/feet, actual knee angles, prop-local joints, desktop-projected joints, stable anchors and support. CSV/PNGs flush continuously; full samples and checks are saved on normal completion/watchdog. A maximum finite-phase sample gap of 50ms is required, so slow capture cannot silently masquerade as ≥20Hz evidence.

Entry and exit checks require advancing actual registered source time and changing source hips plus both actual knees before terminal handoff. The 30° knee spread exclusion gate follows Motion's measured UMA01 source preparation-to-seat range (~21→95°), with independently observed retargeted entry ranges of 86–93° across the three rigs; it is not a claim about aesthetic quality or natural speed. OS origin must stay within 1px throughout each finite phase. Entry preframing and terminal crop compensation are recorded separately at phase boundaries. Endpoint support must coincide within 1px.

For the explicitly fixed front orthographic fixture, physical joint coordinates are reconstructed as `(desktop_pixel_x / actual_ppm, -desktop_pixel_y / actual_ppm, optical_depth)`. The true projection derivative is measured each frame. This retains a common physical coordinate after the occupied scene is released and cancels transparent-window/camera crop translation. Raw world and prop-local coordinates remain in the samples too. Handoff discontinuity gate is 2.5cm plus 1.5m/s times the measured frame interval; all residuals are retained for inspection rather than relabelled as animation quality. This coordinate contract is not reused for perspective without a common-world check.

Optional cancel/support-loss cases interrupt a real partial entry after 25% progress, then require finite state and displacement/seat ownership to clear. These urgent aborts are distinct from normal authored exits. Their results are not covered when `--abort-case none` is used.
