# Authored furniture entry and exit

Furniture entry now keeps the standing contact until a finite imported seated-entry clip completes. The host applies the clip's `root_progress` to the actual standing-to-seat world displacement in the same frames as MotionPlayer applies the source joint rotations. The bounded source anticipation/settling overshoot is preserved; it is not clamped to a synthetic 0–1 ease. Source angular animation remains primary. There is no independent post-pose lowering timer in this path.

Approach X includes the authored backwards hips displacement, projected after applying the furniture-facing heading. Existing desktop walking still remains on its current horizontal support. During entry/exit, the shared furniture transform stays fixed and the avatar receives a temporary world-space presentation offset. At completion the host commits the rendered pivot and optical depth, clears that offset, and requests the exact owned seat. Normal stand and completed computer use run the finite authored exit; urgent cancellation removes the timeline immediately and restores standing lifecycle. No chair-pull animation is claimed or implemented.

`DesktopObjectsHost.has_presentation_transition()`, `presentation_offset()` and `presentation_bounds()` feed the main transform and bounds hooks. Motion owns source selection, joint sampling, finite timeline and cached full transition geometry. Bounds returned by Motion are already corrected for the current host root offset and must not be translated twice.

Validation: `probe_authored_host.gd` uses a real Cheval rig and UMA01 entry, checking 172 assertions: changing knees, exact source root progression (maximum measured host error 7.5e-9 m), stationary native-window origin during sampling, transition bounds, and urgent cancellation cleanup. Its viewport-fit method is deliberately stubbed: this is a host timeline/translation test, not proof of final rendered seating or perspective reach. `test_host_objects.gd` passes 32 lifecycle checks. The separate `test_spatial_transaction.gd` passes 8 assertions for rejected projection rollback and successful configuration persistence. Actual Windows temporal entry, endpoint support and exit captures are required before visual acceptance.

## Scene-space staging work in progress

`authored_staging_foot` and `scene_approach_plan` calculate a real X/Z standing point from the canonical seat anchor and source root delta. Ground Y remains the current standing plane; source X/Z is retained exactly after arrival. `test_scene_staging.gd` passes 37 checks over six headings and three scales. This is geometry validation only: the generic scene-navigation adapter and collision-part routing must be wired before the new path is active. The existing 2D fallback must not be described as true scene-depth navigation.

A full furniture AABB includes hollow access space; omitting the target furniture entirely would instead miss real collisions. Scene navigation therefore needs explicit solid-part obstacles. In particular, a long backwards workstation entry may place its initial standing point under the desk front. That must be resolved with valid geometry/source choreography, not by silently exempting the desk.
