# Independent continuous cape review

**APPROVED as retained exploratory evidence. Candidate 1.2 is not approved for production.** This review covers the original manually advanced 22-second sequence. The [completed automatic-scheduling review](../cape_continuous_automatic/INDEPENDENT-REVIEW.md) supersedes it for temporal acceptance; do not interpret the historical numeric maxima as verified normal production behavior.

The source uses actual MotionPlayer/SeatedTransition logic and actual imported spring modifiers, synchronous twin worlds, matching inputs/world transforms and isolated candidate resources. It contains a measured heading change, model replacement and authored seated entry/exit. It does not contain a chair or the Windows carrier host. Both models receive identical events, but both receive two spring integrations per source frame in this scheduling arrangement.

Independent recomputation from the raw callback tails confirms the documented exit maxima exactly: baseline 28.7657 mm at source frame 1142 and candidate 83.0719 mm at 1144, both at `Sp_Sh_Mantle0_L_04`. The candidate maximum is inside exit rather than an action/load boundary. Source equality is zero, and the 660 sparse mesh comparisons give exit edge difference 0.49166 and minimum area ratio 0.40830. These are candidate-versus-baseline shape differences, not cloth strain. Source hashes match at the recorded run endpoints. See `independent-validation-historical.json`.

I inspected the retained paired exit images at capture indices 0568, 0572 and 0576, including the worst measured source frame. They show different cape configurations during the torso rise; neither bone-length conservation nor the lack of sampled opposed normals establishes a natural transition or collision-free garment. Dense temporal jumps come from the callback data, not an inference from three still images.

Independent timing observers subsequently found that the coroutine source writer creates an engine zero-delta modifier refresh followed by the normal positive-delta pass. The addon consumes node delta for both. Automatic production MotionPlayer instead receives one steady positive-delta pass in the bounded control. The [timing audit](../modifier_timing/INDEPENDENT-REVIEW.md) retains exact source and traces. Consequently the historical sequence is insufficient to make a production-timed accept/reject measurement, although it supports withholding unvalidated tuning. No change to imported defaults follows from this review.
