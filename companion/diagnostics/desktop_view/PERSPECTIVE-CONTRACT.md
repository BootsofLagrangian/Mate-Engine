# Shared perspective contract (implementation in progress)

`desktop_scene_v1` is a right-handed metre frame: +X right, +Y up, +Z back. Its origin is the fixed virtual-camera orbit target for the selected desktop workarea. Moving the pet's native window must not move this frame. A world pose is independent of the viewing angle, FOV, zoom and distance.

`DesktopView.configure_projection` supports orthographic default or true perspective with vertical base FOV20–80 degrees (default45). Lens zoom multiplies focal length via `2*atan(tan(FOV/2)/zoom)`; distance1–12m is an independent camera parameter. Mesh scale remains physical scale. `depth` is positive optical-axis metres. Perspective pixel displacement and pixels/metre require a specified depth or reference world point; omitted perspective references fail explicitly.

`configure_crop(child,reference,crop_pixels)` uses the same world camera transform and near/far planes. The child viewport must equal crop dimensions; its global desktop origin is virtual viewport origin plus crop origin. Crops can extend outside the reference viewport. Perspective crops use an off-axis frustum, not recentered independent perspective cameras. Orthographic crops use an equivalent translated orthographic camera.

Godot4.5 inverse ray/position helpers assume symmetric frusta. The helper inverts `get_camera_projection()` itself to preserve off-axis offsets, then solves the optical-depth plane. The forward projection uses Camera3D.unproject_position. Primary implementation reference: [Godot camera_3d.cpp](https://github.com/godotengine/godot/blob/4.5/scene/3d/camera_3d.cpp), [projection.cpp](https://github.com/godotengine/godot/blob/4.5/core/math/projection.cpp).

`DesktopObjectWindow.set_shared_projection(reference,desktop_origin,transform)` applies canonical physical scale/translation, then fits actual imported vertices to a bounded cropped viewport. Record yaw is already applied to model roots and must not be duplicated in transform. Socket coordinates use the same scene transform. Invalid/near-clipped/far-clipped/oversized geometry returns false; caller must reject or hide, not publish stale contact. `clear_shared_projection()` restores the legacy orthographic path.

Store optional `position_m:{x,y,z}` contains finite non-boolean scalars within[-20,20]m on every axis; these are storage limits, not proof of safe visibility/contact. Missing position is initialized by the host once from a screen anchor and declared depth; view changes preserve the stored position. Spatial capability must only be advertised when the canonical virtual frame and live executor are active. Existing orthographic data omits this optional field.

## Canonical host integration

Main now exposes `spatial_camera()` and `spatial_desktop_origin()`: a fixed 680×760 nominal virtual film rectangle anchored to the selected workarea, with root and furniture windows rendered as exact crops. The origin is not recomputed when the pet window moves. Root crop updates precede avatar placement.

Legacy screen-sized objects migrate once to optional `spatial_unit_scale`; world scale equals record scale times this stored conversion factor. The conversion factor and canonical position survive JSON persistence and never change with viewing FOV/distance. Host migration/rollback checks pass9/0. World-space position edits fail transactionally if their projected geometry is clipped, outside the usable monitor or too large. The window alone returns failure; host decides admission and hides invalid geometry.

Perspective occupied geometry uses the same saved position and record yaw plus the same authored presentation rotation as its standalone model (35° for the computer arrangement). Socket-transfer testing covers this frame agreement; entering contact does not snap the prop depth to the avatar. Authored entry/exit keeps that prop stationary. Camera changes reanchor an already occupied avatar to the unchanged world seat. The legacy orthographic whole-assembly screen nudge is disabled in canonical perspective because it would silently change the stored pose. Authored entry endpoint/depth and skill command handling are owned and validated separately.

Real-main projection fixture54/0 across three imported rigs, two camera angles and three simulated OS origins verifies local foot pivot error≤0.000173px, unchanged canonical camera, and invariant global projection of a fixed world object. It suppresses networking/autonomy/UI and does not establish final Windows motion/occlusion acceptance. Independent source review requested from spatial_review before closeout.
