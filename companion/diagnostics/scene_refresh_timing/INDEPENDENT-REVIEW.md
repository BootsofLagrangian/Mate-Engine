# Scene-interest ownership review

Verdict: **APPROVED for ownership-aware scene-interest suppression and its diagnostic counters**. Exact source and fixture identities are in `review-source-hashes.json`. This review does not establish the cause or correction of the actual Windows periodic frame stalls.

ObjectsHost interaction ownership clears scene targets and invalidates the scene-planning cache. Living checks ownership before selecting scene versus legacy exploration mode, so temporary mode changes cannot bypass suppression. When exploration is unavailable, `clear(true)` preserves an existing suspension. Scene planning resumes only after committed scene-ground ownership or attached foot contact, then the cache rebuilds once until its existing geometry/view/rig key changes. Normal geometry invalidation still rebuilds when required; the code does not suppress legitimate changes indefinitely.

Independent `review_interest_living.gd` executes the actual Living `_refresh_targets` and actual BehaviorDirector using real computer solids, with only exploration selection and unnecessary host services isolated. It exercises exploration disabled during interaction, still disabled after release, then enabled before ground attachment. No obstacle scan occurs while suppressed. Stale scene targets leave both Living's cache and Director's catalogue, their queued move intention is cancelled, and a new request for the removed target rejects with `unknown_target`. Attached foot contact permits exactly one rebuild across two refreshes. All assertions pass in `review-living.json/log`.

The direct author's helper fixture was also independently rerun and passes: changing foot Y normally invalidates plans, occupied refreshes avoid obstacle scans, release waits for ground latch, and model identity change while suspended rebuilds after ground readiness. Results are `review-helper.json/log`.

Review identified and corrected an integration gap in the first patch: helper suppression was only called inside the exploration-enabled branch, while the other branch reset suspension. This could lose ownership state during furniture interaction. The final ordering and preservation flag address that gap.

Counters distinguish refresh calls, rebuilds, the latest refresh cost, latest rebuild cost and current suppression. Latest rebuild time remains a historical value during suppressed/unchanged calls; it is not their current cost. The independent Living fixture measured its rebuild at 721 microseconds, so no claim is made that this change explains the much larger observed Windows pauses. Furniture/session publication remains outside this narrow change; the separate periodic projection-refit investigation remains necessary. No runtime source or Windows process was changed by the reviewer.
